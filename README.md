# 🚖 Project Atlas

> **A consulting-style Business Analysis portfolio project for designing a driver-first, subscription-based ride-sharing platform in Australia.**

---

## 📖 Overview

Project Atlas explores an alternative business model for ride-sharing platforms by replacing traditional commission-based pricing with a fixed monthly subscription for drivers.

The objective is to determine whether a subscription model can improve driver earnings, increase retention, and create a sustainable marketplace while maintaining an excellent rider experience.

This repository documents the complete Business Analysis, Solution Design, Technical Architecture, and Product Strategy from concept to implementation.

---

# 🎯 Project Goals

- Understand the Australian ride-sharing market
- Analyse driver and rider pain points
- Design a subscription-based business model
- Produce professional Business Analysis artefacts
- Design Azure cloud architecture
- Create data models and dashboards
- Develop an executive business case
